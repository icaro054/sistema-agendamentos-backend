# Sistema de Agendamentos - Back-end

API desenvolvida em PHP para o gerenciamento de agendamentos de consultas. Este repositório contém toda a lógica de servidor, regras de negócio e comunicação com o banco de dados.

## Tecnologias Utilizadas
* **Linguagem:** PHP 
* **Banco de Dados:** MySQL
* **Hospedagem Planejada:** Locaweb
* **Ferramentas:** VS Code, Git, Postman/Insomnia (para testar as rotas)

## Como executar o projeto (Ambiente de Desenvolvimento)

1. Certifique-se de ter um servidor local instalado (como XAMPP, WAMP ou Laragon).
2. Clone este repositório na pasta pública do seu servidor (ex: `htdocs` no XAMPP):
   ```bash
   git clone [https://github.com/seu-usuario/sistema-agendamentos-backend.git](https://github.com/seu-usuario/sistema-agendamentos-backend.git)
